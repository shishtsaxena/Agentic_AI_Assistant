# Agentic AI Assistant

A **ChatGPT-inspired Agentic AI Assistant** featuring real-time streaming responses, short-term and long-term memory, database-backed conversations, RAG, MCP integration, agentic workflows, tool calling, observability, and a modern conversational interface built with Python.

## ✨ Features

- 💬 ChatGPT-inspired conversational interface
- ⚡ Real-time streaming responses
- 🧠 Short-Term Memory
- 🗂️ Long-Term Memory
- 💾 Database-backed chat history
- 🔄 Resume previous conversations
- 📚 Retrieval-Augmented Generation (RAG)
- 🔌 MCP (Model Context Protocol) Integration
- 🤖 Agentic Workflows
- 🛠️ Tool Calling
- 📊 Observability & Tracing
- 🎨 Modern React-based UI
- 🔐 Secure API key management using `.env`

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/agentic-ai-assistant.git
```

### 2. Navigate to the project

```bash
cd agentic-ai-assistant
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Git Bash**

```bash
source venv/Scripts/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Create a `.env` file

```env
OPENAI_API_KEY=your_api_key
```

### 7. Run the application

```bash
python main.py
```
